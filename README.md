# NovaRec Privacy

Privacy Policy and legal pages for NovaRec Studio applications.

This repository contains the official privacy and legal information
used by NovaRec Studio for its Android screen recording and live
streaming applications.

## 📱 Applications

NovaRec Studio develops applications focused on:

- 📱 Android screen recording
- 🎥 Video capture
- 🔴 Live streaming
- ⚙️ Media processing
- 📺 Screen and content sharing

## 🔐 Privacy

The repository provides publicly accessible legal documentation
covering how application data is handled.

The privacy documentation may include information about:

- Data collection
- Data usage
- Data storage
- Device and technical information
- Advertising services
- Third-party services
- User rights
- Data security
- Children's privacy
- Changes to the privacy policy
- Contact information

## 📢 Google AdMob

NovaRec Studio applications may use Google AdMob for advertising.

Where applicable, the privacy policy explains the use of advertising
services and the types of information that may be processed for
advertising and measurement purposes.

## 🌐 Legal Pages

The published legal pages are available through GitHub Pages.

The repository is intended to provide a stable and publicly accessible
location for NovaRec Studio's privacy and legal documentation.
